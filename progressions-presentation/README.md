# Прогрессии: задачи перечневых олимпиад

Одностраничная интерактивная презентация (HTML + CSS + JS, без внешних зависимостей) для учеников 10–11 классов.

## Структура
- `index.html` — весь сайт: слайды, задачи, проверка ответов, подсказки и решения.
- Слайд 1 — титульный; слайды 2–11 — задачи; слайд 12 — итоги со списком задач, источников и ответов.
- Навигация: кнопки «Назад / Вперёд», точки-индикаторы, стрелки клавиатуры, свайп на телефоне, адрес вида `#slide-5`.
- Ответы сохраняются в `localStorage` браузера (на сервере ничего не хранится).

## Публикация
GitHub Pages: ветка `main`, папка `/` (root).
