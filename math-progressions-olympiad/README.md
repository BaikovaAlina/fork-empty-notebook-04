# Прогрессии — олимпиадный практикум (10–11 класс)

Интерактивная HTML-презентация с **12 реальными задачами** на арифметическую и геометрическую
прогрессии из перечневых олимпиад школьников по математике: «Покори Воробьёвы горы!»,
«Ломоносов», «Физтех», «Высшая проба», ОММО.

**Сайт для ученика:** https://baikovaalina.github.io/math-progressions-olympiad/

## Что умеет

- 15 слайдов: титульный → памятка с формулами → 12 задач по возрастанию сложности → итоги.
- У каждой задачи: источник (олимпиада, год, класс/этап), уровень сложности (★–★★★),
  поле для ответа с автопроверкой, подсказка и подробное решение.
- Автопроверка понимает дроби (`27/2`), десятичную запятую (`13,5`), списки значений
  (`-1; 15/8`, `128 или 384`), ответы «да/нет».
- Навигация: кнопки «Назад / Вперёд», выпадающий список слайдов, клавиши ← → / Home / End,
  свайпы на телефоне, прогресс-бар, прямые ссылки вида `#slide-7`.
- Прогресс (ответы, статусы, открытые подсказки) хранится в localStorage браузера ученика.
  Никаких серверов и баз данных — только статический файл.
- Итоговый слайд: таблица всех ответов, результат ученика, переход к первой нерешённой,
  сброс прогресса, версия для печати (печатает все слайды вместе с решениями).
- Без внешних зависимостей: один `index.html`, системные шрифты, формулы на чистом HTML/CSS.

## Структура репозитория

```
index.html        — вся презентация (HTML + CSS + JS в одном файле)
README.md         — этот файл
SOURCES.md        — список задач с источниками и ссылки на архивы
tools/verify.py   — скрипт проверки всех условий и ответов (sympy + подстановка)
.nojekyll         — отключает обработку Jekyll на GitHub Pages
```

## Проверка корректности

Все 12 ответов проверены двумя независимыми способами: символьным решением уравнений
и прямой подстановкой в условие (47 проверок), плюс 35 смоук-тестов интерфейса.

```bash
pip install sympy
python3 tools/verify.py
```

## Как обновлять

Отредактируйте `index.html` (данные задач — в массиве `PROBLEMS` в начале скрипта),
закоммитьте в `main` — GitHub Pages обновится автоматически в течение пары минут.

Локальный просмотр: просто откройте `index.html` в браузере.

## Публикация

Презентация опубликована как папка `math-progressions-olympiad/` этого репозитория
через GitHub Pages (ветка `main`, корень `/`). Настройки: Settings → Pages.
Если позже понадобится отдельный репозиторий — достаточно скопировать содержимое
этой папки в его корень и включить Pages там.
